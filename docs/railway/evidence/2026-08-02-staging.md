## Sandbox exception

Railway staging was first exercised with the image default
`EGO_CHROME_NO_SANDBOX=0`. Deployment
`8581c87a-f37e-42ab-aa3f-9f6c1c854ddc` terminated Chromium with `SIGTRAP`, so
the staging service explicitly uses `EGO_CHROME_NO_SANDBOX=1`. The final image
still defaults to sandboxed Chromium. The managed browser policy suppresses the
warning banner only and does not mitigate this runtime exception.

## Unverified gates and residual risk

- viewer-role keyboard and mouse denial has not received a live input-negative
  assertion; only server-assigned role authentication was verified;
- agent/human control is an explicit `handOffTaskSpace` / `takeOverTaskSpace`
  procedure, not an automatic lease;
- volume backup restore, hard-kill recovery, and quantitative interaction
  latency remain unverified;
- Railway raw CDP path returned 404 publicly, but a separate private-interface
  network probe remains outstanding;
- websites can independently expire or revoke sessions, require MFA, or reject
  a datacenter IP;
- production Hermes was not changed and this staging image was not promoted to
  production.
